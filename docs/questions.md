# Questions

THere should be some default set of available questions, and the user can add these
or write custom ones.

My main inspiration is the dialectical behavioral therapy diary card. which asks such questions as 

- Highest urge to (0-5)
    - commit suicide
    - self harm
    - use alcohol or drugs
- Highest rating for each day (0-5)
    - Emotional Misery
    - Physical misery
    - joy
- Alcohol/Drug use (N)
    - NUmber of useages & what was used
- Medications use (N)
    - did you take your prescriptions
- Actions taken (N)
    - Self Harm
    - Lied
    - Used DBT Skills

I added 

- Highest level of (0-5)
    - Depression
    - Anxiety

There is also

used skills 
0. Not thought about or used
1. Thought about, not used, didn't want to
2. Thought about, not used, wanted to
3. Tried, but couldn't use them
4. Tried, could do them, they didn't help
5. Tried, could use them, helped
6. Auomatically used them, didn't help
7. Automatically used them, helped


Urges to: (0-5)
- Quit Therapy
- Use Drugs
- Commit suicide

Belief I can change my (0-5)
- Emotions
- Actions
- Thoughts


SOme boolean questions:
Simply did you use X skill today

Mindfullness:
- Wise Mind
- Observe, Just notice
- Describe, Put words on, Just the facts
- Participate: Enter into the experience
- Nonjudgementally
- One-mindfully: Present moment
- Effectively: Focus on what works

Interpersonal Effectiveness
- DEAR (Describe, Express, Assert, Reinforce)
- MAN (Minful, Appear Confident, Negotiate)
- GIVE (Gentle, Interested, Validate, Easy Manner)
- FAST (Fair, no Apologies, Stick to Values, Truthfully)
- Walked the middle path, Dialectics
- Validation
- Strategies to change behavior

Emotional REgulation:
- Checked the facts
- Did opposite action
- Problem Solved
- Accumulated Positive Emotions (A)
- Built Mastery (B)
- Coped Ahead (C)
- Reduced Vulnerability, PLEASE (Cre for: Physical ills, Eating, Avoid mood altering substances, Sleep, Exercise)
- Mindfullness of current emotion

Distress Tolerance
- STOP 
- Pros and cons
- TIPP (Temperature, Intense Exercise, Paced Breathing, Paired Muscle Relaxation)
- Distracted
- Self-soothed
- Improved the moment
- Radical Acceptance
- Half-smiling, willing hands
- Willingness, MIndfullness of current thoughts

These questions really helped to put me in the right frame of mind.
